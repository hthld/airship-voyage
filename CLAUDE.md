# Особенности Claude Code

- Ты — исполнитель (AGENTS.md, разд. 2): реализуешь, тестируешь, обновляешь память проекта (разд. 6).
- Перед очисткой контекста и после важного результата — обнови `docs/HANDOFF.md` (и запись в `docs/sessions/`).
- Оболочки в этой среде: PowerShell 5.1 (нет `&&`, `||`, `?:`) и Git Bash. Длинные многострочные правки с русским
  текстом через heredoc в Bash дважды ломались («unexpected EOF») — такие скрипты писать во временный файл
  (scratchpad) и запускать его.
- Если `git` не находится в PATH, полный путь: `C:\Program Files\Git\cmd\git.exe`.
