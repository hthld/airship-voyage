# Решения Airship Voyage

ID постоянные. Как устроено сейчас — `docs/ARCHITECTURE.md`; здесь — что решено и почему.

## Источник решения

- **Утверждено владельцем** — правило или прямое указание владельца (раньше — `CLAUDE.md`, теперь — `AGENTS.md`)
  либо требование ТЗ.
- **Действует** — инженерное решение, реализованное и покрытое тестами. Владелец работу принимал, но отдельного
  обсуждения именно этого решения в записях нет. Пересматривать можно; при изменении — обновить здесь.
- **Предложение** — не утверждено.
