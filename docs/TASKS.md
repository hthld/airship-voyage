# Задачи Airship Voyage

ID постоянные и не переиспользуются: `AV-NNN` — работа над проектом, `AUD-NN-MM` — замечания аудитов
(тексты — `docs/reviews/`).

Статусы:
- `active` — в работе;
- `next` — следующая;
- `waiting` — ждёт владельца (разрешения или проверки в игре);
- `done` — сделано (указано, где: коммит или «не закоммичено»);
- `proposed` — предложение, не утверждено;
- `backlog` — отложено.
